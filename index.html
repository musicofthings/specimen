        What the scores mean. Uniqueness counts how many channels already answer to this name and how big they are — an exact match with a large audience is what actually buries you in search. Memorability is computed from the name itself: length, word count, syllables, sound repetition, and how many ways it can be misspelled. It never touches the network.

        Handle checks cost 1 unit each and are usually enough to kill a bad candidate early. Run the full scan only on names that survive.
